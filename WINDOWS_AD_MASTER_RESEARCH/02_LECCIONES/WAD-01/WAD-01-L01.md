## 1. Objetivo

Distinguir edición, rol y estado de soporte de un host Windows para inventariarlo sin modificarlo.

Prerrequisitos: ninguno; puedes comenzar desde cero.

## 2. Comprende el mecanismo

Windows no es un solo producto. **Cliente** (Windows 10 y 11) está pensado para sesiones interactivas, productividad y gestión de dispositivos. **Servidor** (Windows Server) añade roles de infraestructura como DNS, archivos, virtualización o servicios de directorio, con modelos de administración y condiciones de despliegue distintos. No conviene enseñarlo como «Windows Server = Windows 11 con más opciones»: cambian las superficies operativas.

Cada producto se ofrece en **ediciones** (por ejemplo, Home, Pro, Enterprise en cliente; Standard, Datacenter en servidor) y en **ramas o canales** con calendarios distintos. La edición condiciona funciones disponibles, límites de hardware y derechos de uso. Una capacidad puede existir técnicamente y no estar licenciada: soporte de producto, disponibilidad de función y licencia **no** son lo mismo.

El **ciclo de vida** marca el estado de soporte: una versión puede estar en soporte estándar, en soporte extendido (solo actualizaciones de seguridad en condiciones concretas) o fuera de soporte. Las fechas se publican por edición y rama, así que un inventario serio registra producto, edición, versión/compilación y su estado de soporte en una fecha.

En servidor existe además la **opción de instalación**: *Server Core* (sin interfaz gráfica estándar, se administra con PowerShell, SConfig, WinRM o herramientas remotas) y *Desktop Experience* (con escritorio). Core no significa «sin administración»; significa menos componentes gráficos instalados. La conversión entre ambas opciones **no se hace in situ**: según la documentación actual exige reinstalar.

### Vocabulario de apoyo

- **Edición**: variante comercial de un producto (Home, Pro, Enterprise, Standard, Datacenter).
- **Rama/canal**: línea de versiones con su propio calendario de mantenimiento.
- **Compilación (build)**: número exacto de versión; útil para comparar dos equipos.
- **Soporte estándar / extendido**: fases del ciclo de vida con distinto nivel de actualizaciones.
- **Server Core / Desktop Experience**: opciones de instalación de Windows Server.
- **SKU**: identificación comercial que determina funciones y licencia.

[Glosario](../../05_RECURSOS/GLOSARIO.md). No necesitas memorizar fechas: lo importante es saber dónde consultarlas y cómo registrar la que aplique a tu host.

## 3. Caso resuelto

**Datos sintéticos para análisis; no son una captura ni una ejecución real.**

> Caso sintético: un servidor de laboratorio informa `Windows Server 2022` en una compilación de una rama LTSC. El equipo de operaciones pregunta si conviene planificar su migración este año.

La respuesta razonada no es «sí» ni «no», sino **dónde mirar**: primero se confirma producto, edición y compilación exactas; después se consulta el ciclo de vida oficial de esa rama en una fecha concreta. Si la rama está en soporte extendido, solo llegan actualizaciones de seguridad con condiciones; eso cambia la urgencia y el plan. El dato relevante es el estado en la fecha de la decisión, no una fecha memorizada.

## 4. Práctica individual

Un host de laboratorio informa producto `Windows Server 2025` y una compilación LTSC. Antes de decidir si sigue soportado, enuncia **qué tres datos** registrarías y **dónde** consultarías su estado de soporte.

Entrega una respuesta razonada: identifica los datos que utilizas, la decisión o cálculo, y el límite de tu conclusión. Resuelve antes de consultar el solucionario. Esta práctica es de análisis documental; su resolución no acredita haber instalado ni configurado un host real.

## 5. Evalúa lo aprendido

Responde ambas preguntas y justifica por qué las otras opciones no se sostienen con los datos.

### Pregunta 1

¿Qué describe mejor la diferencia entre Windows cliente y Windows Server?

- A. Son el mismo producto con distinto nombre comercial
- B. Cliente se orienta a sesiones interactivas y servidor añade roles de infraestructura con otra administración
- C. Servidor es Windows 11 con más opciones activadas
- D. La única diferencia es el color del escritorio

### Pregunta 2

¿Qué afirmación sobre Server Core es correcta?

- A. Al no tener interfaz gráfica estándar, no se puede administrar
- B. Se puede convertir a Desktop Experience in situ sin reinstalar
- C. Se administra con PowerShell, SConfig, WinRM o herramientas remotas y tiene menos componentes gráficos
- D. Obliga a usar siempre escritorio remoto

## 6. Aplicación profesional

- SOC: Registrar producto, edición y compilación para situar un host dentro de su línea de soporte antes de investigar.
- Red Team autorizado: Distinguir una capacidad técnica de un derecho de uso; no evaluar funciones no autorizadas.
- Evidencia de la etapa: Ficha de host con producto, edición, compilación y estado de soporte en una fecha.
- Criterio de dominio: Identifica versión/edición y estado de soporte sin inventar fechas ni equivalencias.
