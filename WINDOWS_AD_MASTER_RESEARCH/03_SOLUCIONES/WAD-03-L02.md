# Soluciones — WAD-03-L02

Material de revisión: consultar después de resolver.

## Práctica individual

Dos procesos del mismo usuario pueden diferir porque cada uno lleva su propio **token de acceso**: uno puede tener un token **filtrado** y el otro, uno **completo** (elevado) tras el consentimiento de UAC. La evidencia se recoge observando la identidad, los grupos y los **privilegios efectivos** de cada proceso, y comparando su **nivel de integridad**. Para separar los dos conceptos: un **privilegio** es una capacidad de la identidad (por ejemplo, realizar copias de seguridad o depurar procesos) y un **permiso** es la autorización sobre un objeto concreto (escribir en una carpeta). Límite: el token explica qué puede hacer el proceso, no por qué su presencia es legítima.

### Criterios observables

- Explica que la diferencia está en el token y no en la cuenta.
- Distingue token filtrado de token completo y lo relaciona con UAC.
- Propone evidencia observable (privilegios efectivos, nivel de integridad).
- Separa privilegio de permiso con un ejemplo.

Valora precisión, relación con los datos y límites. Una respuesta alternativa puede ser válida si justifica sus supuestos y no contradice el caso. No se autocorrige como dominio práctico.

## Pregunta 1

**Respuesta: B. Contra el token de acceso del proceso que la ejecuta**

La comprobación de acceso usa el token del proceso; la contraseña solo interviene al iniciar sesión y el nombre no determina derechos.

## Pregunta 2

**Respuesta: B. Reemplaza el token filtrado por un token completo, previa aprobación**

UAC pide consentimiento y entrega un token completo para esa operación; no cambia la contraseña ni concede privilegios de forma permanente.
