# SP-R04-L07 — Expresiones, multivalor y patrones

## 1. Pregunta esencial

Muchos logs llegan como texto y listas: una parte del trabajo del analista consiste en extraer campos, aplicar condiciones y manejar valores multivalor sin inflar artificialmente los eventos. `rex` extrae datos por patrón, `eval` transforma campos y `mvexpand` multiplica filas por cada valor de un campo multivalor; contar filas después de expandir no mide necesariamente eventos originales.

**Objetivo verificable:** Usar rex, mvexpand, eval con supuestos explícitos.

## 2. Modelo mental y conceptos

1. `rex field=_raw "user=(?<extraido>[^ ]+)"` usa grupo con nombre: valida el formato y escapes contra ejemplos reales.
2. `eval` permite construir flags y tipos derivados; documenta qué significan las cadenas originales y cómo trata null.
3. `makemv delim="," roles | mvexpand roles` sólo tiene sentido si roles contiene una lista separada de esa forma; mvexpand incrementa el número de filas.
4. Si el campo no está presente o el patrón cambia, clasifica el evento como no parseado y revisa cobertura en lugar de asumir un valor normal.

## 3. Procedimiento guiado

1. Examina una muestra de `_raw` y redacta una expresión que capture únicamente user.
2. Prueba mentalmente contra ejemplos que no contienen `user=` o con espacios; describe fallos esperados.
3. Imagina roles=admin,operator: mvexpand genera dos filas para un único evento.
4. Cuenta identificadores originales distintos cuando tu métrica sea “eventos” y no “roles observados”.

## 4. SPL ilustrativo — no ejecutado

```spl
index=INDICE_LAB sourcetype=SOURCETYPE_LAB earliest=-24h
| rex field=_raw "user=(?<usuario_extraido>[^ ]+)"
| eval identidad=coalesce(user, usuario_extraido)
| table _time identidad _raw
```

**Comparación con otro patrón sobre el mismo objetivo:**

```spl
index=INDICE_LAB sourcetype=SOURCETYPE_LAB earliest=-24h
| makemv delim="," roles
| mvexpand roles
| stats count AS filas_expandidas BY roles
```

**Interpretación, condiciones y alcance:** Segundo ejemplo presupone roles como texto CSV y en ese índice; no ejecutes sobre producción sin conocer el esquema. Para uso profesional, controla cardinalidad y coste de memoria de mvexpand.

**Nota de seguridad:** `INDICE_*`, `SOURCETYPE_*` y nombres de lookups son marcadores pedagógicos. No están instalados ni descubiertos en tu laboratorio. Los SPL de este bloque son búsquedas de lectura, no indicaciones para modificar índices, apps, permisos o configuraciones.

## 7. Solucionario con razonamiento

- **SP-R04-L07-Q01: C** — mvexpand crea una fila por valor del campo multivalor.

- **SP-R04-L07-Q02: B** — rex realiza extracción en el pipeline, no reindexación.

- **SP-R04-L07-P01:** Un evento fuente genera dos filas tras expandir roles. Regex `user=(?<usuario_extraido>[^ ]+)` captura alice; si falta user no debe inventar identidad. Mantener un identificador original para comparar cardinalidad antes/después.
