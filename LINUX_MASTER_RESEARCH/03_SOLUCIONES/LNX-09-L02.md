# Soluciones — LNX-09-L02

Material de revisión: consultar después de resolver.

## Práctica individual

La consulta de propiedad revela **qué paquete registra** la ruta en la base de datos local. No demuestra que el contenido actual coincida con el original, porque la base local puede haberse alterado y porque registra propiedad, no coincidencia de contenido.

Para elevar la conclusión haría falta comparar contra una referencia externa confiable o una copia preservada, además de correlacionar la transacción de paquete o el despliegue autorizado y la temporalidad. El límite: procedencia efectiva y confianza relativa no equivalen a una prueba absoluta de integridad.

### Criterios observables

- Explica que la consulta usa la base de datos local y puede ser alterada.
- Distingue propiedad de coincidencia del contenido.
- Propone referencia externa o copia preservada para elevar la conclusión.
- Reconoce que no estás ante una prueba absoluta de integridad.

Valora precisión, relación con los datos y límites. Una respuesta alternativa puede ser válida si justifica sus supuestos y no contradice el caso. No se autocorrige como dominio práctico.

## Pregunta 1

**Respuesta: B. Que la definición efectiva proviene de esa ruta, que es una personalización o despliegue, no necesariamente hostil**

Una ruta bajo la administración del sistema indica personalización o despliegue, no hostilidad. No prueba que el paquete original se borrara ni que no existan drop-ins aplicados.

## Pregunta 2

**Respuesta: A. Porque consulta una base de datos local que podría haberse alterado y registra propiedad, no coincidencia del contenido actual**

La consulta usa una base local potencialmente comprometida y registra propiedad, no la coincidencia del contenido actual. Sí lista rutas, funciona en varias distribuciones y no verifica firmas en cada lectura.
