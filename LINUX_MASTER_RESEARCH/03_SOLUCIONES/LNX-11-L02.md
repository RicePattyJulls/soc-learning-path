# Soluciones — LNX-11-L02

Material de revisión: consultar después de resolver.

## Práctica individual

La conclusión no se sostiene porque la **herramienta no corresponde a la familia**: el comando de otra distribución consulta una base distinta y su error describe la ausencia de esa base, no la ausencia de dueño. Para una ruta en Arch la pregunta se responde con `pacman -Qo`, que consulta la base de pacman.

La elección correcta parte de identificar la distribución —por ejemplo con `/etc/os-release`— y usar el comando de esa familia: `pacman -Qo` en Arch, `dpkg -S` en Debian o `rpm -qf` en RPM. Así, la ausencia de resultado solo se interpreta si la herramienta es la adecuada.

Límite: la respuesta describe la base **local** del host; si esa base fue alterada, el resultado hereda ese límite y exige validación contra una referencia externa de confianza.

### Criterios observables

- Identifica el error como uso de la familia equivocada.
- Propone `pacman -Qo` para la propiedad de una ruta en Arch.
- Sugiere identificar la distribución antes de elegir el comando.
- Reconoce el límite de la base de datos local.

Valora precisión, relación con los datos y límites. Una respuesta alternativa puede ser válida si justifica sus supuestos y no contradice el caso. No se autocorrige como dominio práctico.

## Pregunta 1

**Respuesta: A. Con `pacman -Qo`, que responde a qué paquete pertenece una ruta en Arch**

`pacman -Qo` consulta la base de pacman y responde a qué paquete pertenece una ruta. Los comandos de otras familias consultan bases distintas, no son universales y no se sustituyen entre sí; en Arch sí se puede conocer el dueño de una ruta.

## Pregunta 2

**Respuesta: D. Porque puede mezclar bases de datos y binarios de revisiones distintas y romper la consistencia**

Sincronizar bases y no actualizar el sistema de forma coherente puede mezclar revisiones distintas y romper la consistencia; el patrón recomendado es una actualización transaccional coherente. No se trata de firmas, reinicios automáticos ni borrado del historial.
