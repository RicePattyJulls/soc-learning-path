# SOC Learning Path · V2.2 panorámica

Versión 0.2.2. Cambio de layout autorizado sobre V2.1. No se ha extendido el arte premium a las otras doce regiones ni al atlas.

## Dirección

Se conserva la paleta existente: noche #102d54, tinta #17365c, pradera #a8d965, río #168ddd, violeta #7948df y oro #ffc45f. Trebuchet MS / DejaVu Sans siguen sin descargas. La decisión visual es abrir el paisaje, conservando una superficie tranquila y acotada para estudiar.

```text
Escritorio: margen 16–32 px | marca · navegación · nivel | margen 16–32 px
                          selector directo de regiones
                bienvenida | progreso y estadísticas acotadas
              paisaje panorámico, camino y placas de tamaño fijo
                         campamento de tres columnas

Móvil: selector → bienvenida/progreso → recorrido vertical V2.1
Lecturas: se conservan los límites de ancho y las líneas de texto.
```

## Implementación

- `adventure.css`: elimina límites de 1600 px del atlas/cabecera y 1560 px de las regiones. Un token `--academy-gutter` de 16–32 px alinea los bordes. Móvil conserva 8 px en atlas y 12 px en regiones/cabecera, con safe areas.
- `full-width.css`: cabecera con navegación centrada cuando hay espacio; bienvenida hasta 565 px y progreso regional hasta 390 px. Desde 1600 px, progreso/estadísticas del atlas se colocan en paralelo, con un máximo conjunto de 920 px. El campamento acota nivel/guía; las recompensas usan placas de hasta 280 px. No se ensanchan las vistas de lectura, biblioteca ni estadísticas.
- `mapLayout` recibe el ancho real de la escena. El viewBox usa píxeles del escenario en escritorio/tableta: se recalculan posiciones horizontales, manteniendo cuatro/tres columnas y orden serpenteante. La altura no crece proporcionalmente al monitor. Símbolos y placas mantienen su tamaño; no hay `preserveAspectRatio="none"`, zoom ni escalado independiente de ejes.
- `useAdventureLayout` reutiliza el ResizeObserver y las mediciones existentes. Paisaje, caminos, cruces, nodos y cofre comparten coordenadas. Se mide en efecto, sin leer el DOM durante render. `fitMapLabels` conserva el espacio para títulos extensos.
- Móvil mantiene el viewport lógico de 400 unidades y el espaciado vertical medido de V2.1. El retorno usa los mismos IDs y el parámetro `nodo`, con foco/scroll al elemento real.
- Sin animaciones nuevas: la skill `animate` se aplica para conservar feedback de 120–200 ms con transform/opacity, curva existente, navegación por teclado instantánea y movimiento reducido. Resize no anima dimensiones ni posiciones.
- `Artwork.tsx`, `PilotLandscape.tsx` y `pilot-landscape.ts` permanecen idénticos. Solo la primera región usa el renderizador premium.
- `original-map-geometry.ts` calcula los cruces del río heredado, incluidas las tangentes reflejadas de sus curvas SVG. `AdventureMap` recoloca/orienta y ajusta la longitud del puente previo sobre cada cruce real, sin activar el dibujo premium en las otras regiones. Corrige el puente aproximado que quedaba sobre tierra al abrir el panorama.

## Contrato educativo

SC-200.md, generadores, catálogo/IDs, payloads, lectores, cuestionarios y motores de XP/estados no cambian. `integridad.json` comprueba las huellas protegidas. Conservados: 13 capítulos, 76 lecturas, 719 pasos, 35 actividades revisadas en nueve lecturas y 67 lecturas pendientes; 80% para aprobar, dominio separado de completar y premios únicos.

`soc-learning-path:progress:v1` sigue de solo lectura. `soc-learning-path:learning:v2` conserva esquema, fusión y persistencia; no hay almacenamiento paralelo ni migración nueva. Los navegadores de prueba usan contextos temporales, sin abrir el perfil personal. Usar el mismo navegador/perfil y `http://127.0.0.1:5173/` para recuperar el guardado personal.

## Validación reproducible

Entrega, cifras de ancho y comparativas: `output/playwright/v22-full-width/ENTREGA.md` e `index.html`. Las referencias antes se capturaron desde el build V2.1 en las mismas seis resoluciones.

```sh
npm run verify
node tests/e2e.mjs --full-width --base-url http://127.0.0.1:5173/
node tests/e2e.mjs --base-url http://127.0.0.1:5173/
node tests/e2e.mjs --visual --base-url http://127.0.0.1:5173/
```

`npm run test:full-width` crea su servidor si Node puede escuchar puertos. Aquí se usa Python para servir el build. Se añade una regresión unitaria de geometría y la suite de 390/768/1024/1440/1920/2560 px, más 320 px y límites de breakpoint. La suite visual cambia únicamente su espera de resize: ahora comprueba el ancho real en lugar de 900/1200 px. Las pruebas educativas existentes se conservan.

La revisión de foco, objetivos táctiles, safe areas y movimiento sigue las [Web Interface Guidelines](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md). Las pruebas automáticas no sustituyen Safari/Firefox, lector de pantalla ni dispositivos físicos.

## Extensión artística propuesta · no implementada

Reutilizar `AdventureMap`, `RegionNavigation`, estados/placas, tokens, cruces y exclusión de vegetación. Extraer de la piloto terreno, montaña, árbol y puente como piezas/defs comunes configurables; evitar doce componentes completos copiados. Mantener aprendizaje y guardado fuera de la capa visual.

Variar silueta del horizonte, terrazas/roca, paleta secundaria, vegetación y agua, usando temas de valle, bosque, altura, agua, nieve y cañón. Conservar ríos/caminos/puentes coherentes y estados expresados también con texto/iconos. No añadir contenido educativo en la decoración.

Tras aprobación, comenzar por dos regiones, revisar en las seis resoluciones y continuar por grupos. El atlas conservaría su arte salvo autorización específica.

Rendimiento estimado: se monta una región a la vez; el DOM visible no se multiplicaría automáticamente por trece. Crecerían el bundle de formas, los símbolos visibles y el coste de calcular cruces. Mantener defs compartidos, memoización y densidad acotada; valorar carga diferida si el peso crece. Antes de cada grupo, medir bytes gzip, DOM, tareas largas, CLS y carga con tres muestras por versión, CPU 4× en móvil. Medir scroll/interacción aparte para afirmar fluidez o FPS. Es una evaluación de costes, no una mejora de rendimiento declarada.

Pendientes: Safari/Firefox, dispositivos físicos, lector de pantalla/contraste manual, 67 lecturas por enriquecer e importación/restauración del progreso. Splunk sigue reservado. Sin commits ni publicación.
