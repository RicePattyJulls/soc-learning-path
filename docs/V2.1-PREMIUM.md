# SOC Learning Path · V2.1 premium

Versión 0.2.1. Alcance autorizado: correcciones globales de usabilidad y una única región piloto premium. **No extender las ilustraciones sin aprobación del usuario.**

## Implementación

- `src/tokens.css`: paleta central y tiempos de movimiento. Tinta #17365c; azul noche #102d54; verde #159368; pradera #a8d965; río #168ddd; violeta #7948df; oro #ffc45f. Se mantiene Trebuchet MS / DejaVu Sans local, sin descargas.
- `src/premium.css`: acabados reutilizables para botones, nodos, placas, lector, actividades, resultados, biblioteca, repaso, estadísticas y campamento. Relieve mediante gradientes y sombras estáticas. Hover y pulsación tienen feedback sin introducir acciones decorativas falsas.
- `RegionNavigation`: selector nativo con etiqueta, navegación anterior/siguiente y enlaces a índices reales. No calcula ni concede desbloqueos.
- `Roadmap`: el selector existente se presenta antes del atlas. Se conservan las trece regiones y la apertura independiente.
- `useAdventureLayout`: mide en un efecto la bienvenida y las placas, agrupa lecturas del DOM y adapta el espacio necesario; respeta los títulos completos y la posición del cofre. Las distancias móviles dependen de la altura de las tarjetas, reduciendo huecos fijos excesivos.
- `PilotLandscape`: paisaje SVG nuevo de Licencia y onboarding, con montañas en capas, caras de roca, terrazas, tres árboles reutilizables, arbustos, rocas, flores, río y puentes. `Artwork.tsx` conserva byte a byte las ilustraciones V2 de las otras doce regiones y del atlas.
- `pilot-landscape.ts`: geometría visual pura compartida por río, puentes y zonas sin vegetación. Interseca segmentos muestreados del camino y el agua; los puentes se alinean con la tangente del camino. Los árboles excluyen agua, camino y zonas de lectura. Se calcula una vez por geometría y se comparte entre los renderizadores memoizados.
- El nombre accesible del cofre completado distingue regiones y etapa.

## Movimiento

- Pulsación: transform, 120 ms, curva `--ease-out` existente.
- Hover de nodo: elevación breve de 4 px, solo con puntero preciso; no se anima el paisaje.
- Llegada a atlas/región: únicamente la tarjeta de bienvenida, opacidad y 6 px de desplazamiento, 200 ms, tras navegación con puntero. El teclado permanece instantáneo.
- Cambio de tarjeta: se mantiene el mecanismo existente, 150 ms, con opacidad y transform.
- Dominio demostrado: medallón con entrada de 200 ms al aparecer el resultado, solo con puntero. Cofre: confirmación breve de 200 ms cuando cambia realmente a completado; no se repite por visitar un cofre ya conseguido.
- Movimiento reducido elimina desplazamientos, pulsación y animaciones de llegada/cofre. No hay bucles ambientales, parallax, desenfoques animados ni bibliotecas de animación nuevas.

## Contrato educativo

No cambian `SC-200.md`, catálogo, payloads, actividades, compiler ni el motor de progreso. `LearningReader.tsx` y `QuestionCard.tsx` mantienen su comportamiento; la apariencia procede de CSS. En `LearningReader` se añade únicamente `role="group"` al contenedor ya etiquetado de actividades, para dar semántica válida a su nombre accesible. Las claves V1/V2, persistencia, exportación, migración, 80% para aprobar, premios únicos y niveles siguen intactos. No se ha añadido contenido Splunk, autenticación ni backend.

La verificación de huellas está en `output/playwright/v21-premium/integridad.json`. Las pruebas de navegador usan contextos temporales y fixtures de progreso propios; nunca el perfil personal.

## Validación reproducible

```sh
npm run verify
npm run test:browser
npm run test:visual
npm run test:premium
```

Las tres suites pueden usar un servidor existente:

```sh
node tests/e2e.mjs --base-url http://127.0.0.1:5173/
node tests/e2e.mjs --visual --base-url http://127.0.0.1:5173/
node tests/e2e.mjs --premium --base-url http://127.0.0.1:5173/
```

Se añadió una comprobación opcional de accesibilidad con axe-core 4.10.3, ejecutado solo en pruebas y sin dependencia de producción. Requiere un archivo local del motor:

```sh
node tests/e2e.mjs --a11y --axe-path /ruta/axe.min.js --base-url http://127.0.0.1:5173/
```

La comparación de rendimiento requiere una instancia de la versión previa en otro puerto; usa tres muestras por versión/anchura, perfiles aislados y CPU 4× a 390 px:

```sh
node tests/e2e.mjs --performance --before-url http://127.0.0.1:5174/ --base-url http://127.0.0.1:5173/
```

La suite visual heredada conserva sus diez grupos. Su primera comprobación se actualizó para exigir decoración SVG reutilizada con un presupuesto acotado de 10–149 símbolos, en lugar de imponer una densidad mínima de 46; ahora la piloto usa menos árboles. Las mediciones esperan el final de las nuevas transiciones breves para comprobar que no quedan animaciones en reposo. No se redujeron las comprobaciones educativas, navegación, dominio o persistencia.

Resultados finales, capturas y limitaciones: `output/playwright/v21-premium/ENTREGA.md` y `index.html`.
